How to Install & Play

  1. Download or copy the skill file above.
  2. In your book's project folder, find (or make) a .claude/skills/ folder.
  3. Save the file inside it as SKILL.md in its own folder — e.g. .claude/skills/interactive-fiction/SKILL.md.
  4. Open Claude Code in that project and type "start the story" (or whatever start command you set in Section 6).
  5. Claude reads the scene, you reply with a choice number or a custom action, and the story unfolds. Use your Save point command before you close — paste the summary back next time to pick up where you left off.
Pro move: Run a few turns, notice what feels off — too short, forgets your inventory, choices too obvious — then come back here, adjust the matching section, and regenerate. Iterating the skill is how you tune the game. (That's exactly what the Skill Testing Lab in Lesson 8 is for.)
