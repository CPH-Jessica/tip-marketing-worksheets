The 8-Pass System — Quick Reference

Structural Passes (1-3)
Pass 1
Quality Check
Basic prose quality, tone match, outline adherence, arc consistency, heat level verification.
Pass 2
Plot Hole Checker
Logic gaps, character knowledge, setup/payoff tracking, contradictions with prior chapters.
Pass 3
Timeline Consistency
Days/weeks/seasons, travel time, character ages, concurrent events, season/weather match.
Prose Passes (4-6)
Pass 4
Line Edit
Weak verbs, filter words, echoes, adverb crutches, AI-isms, sentence variety.
Pass 5
Dialogue Polish
Character voice differentiation, subtext, banter rhythm, action beats, exposition dumps.
Pass 6
Heat Scene Edit
Emotion over mechanics, sensory balance, pacing, voice consistency during intimacy.
Architectural Passes (7-8)
Pass 7
Developmental Edit
Scene justification, pacing drag, character arc consistency, the Slash Editor pass.
Pass 8
Voice Audit
Pen name calibration, AI drift detection, manuscript-wide voice consistency.
