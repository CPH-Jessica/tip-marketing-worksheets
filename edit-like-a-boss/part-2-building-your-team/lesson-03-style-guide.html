How To Install This As A Claude Skill

  1. Click Generate Style Guide above. Copy the output.
  2. Open Claude. Create a new SKILL.md file in your skills directory.
  3. Add the frontmatter header at the top (see template below).
  4. Paste your generated style guide content below the frontmatter.
  5. Save the file. Restart Claude or refresh the skills directory.
  6. Test by asking: "Use the [pen name] style guide skill to write a scene where..."

SKILL.md frontmatter template:

--- name: [pen-name-style-guide] description: Use this skill when writing or editing any [Pen Name] fiction. [Pen Name] is a [genre] author. Heat level [X]/5. --- # [Pen Name] Style Guide [PASTE YOUR GENERATED STYLE GUIDE HERE]

Upgrade Path — Use Claude's Skill Creator

If you want to take your style guide further, use Claude's built-in Skill Creator skill. It will interview you and refine your guide into a polished, optimized skill file.

The exact prompt to use:

Use the Skill Creator to help me build (or refine) a pen name style guide skill. Here is my draft style guide so far: [PASTE YOUR GENERATED STYLE GUIDE HERE] Walk me through each component and help me sharpen it. Ask me follow-up questions where my answers are vague or generic. Push back if anything contradicts itself. I want this to be specific enough that another writer reading it would know exactly what this pen name sounds like. When we're done, format the final result as a Claude SKILL.md file with proper frontmatter that I can save directly to my skills directory.
Why this works: The Skill Creator is built to interrogate vague instructions and demand specificity. Your guide will come out sharper than what you can build alone on a worksheet.

Test Your Style Guide

Once your style guide is installed, run this test to see if it's working.

  1. Pick a chapter prompt you've used before. Something simple — a meet-cute scene, an argument, a kiss.
  2. Run it through the AI WITHOUT your style guide active. Save the output.
  3. Run the same prompt through the AI WITH your style guide active. Save that output.
  4. Read both side by side. The difference should be obvious.
  5. If the difference is NOT obvious, your guide needs more detail — particularly in Component 9 (sample passages) and Component 3 (voice markers).
The test does not lie. Either the guide is doing the work or it isn't. Iterate based on what you see.

The Iteration Cycle

Your style guide is not a write-once document. It evolves.

  1. Run Pass 8 (Voice Audit) from Day 1 on a finished chapter.
  2. The AI flags a line as off-brand. Look at it.
  3. Ask: was the AI right?
  4. If yes: Style guide is working. Fix the line. Move on.
  5. If no: Style guide is missing something. Either the voice markers are too rigid, or there's no example of that kind of moment. Add the missing piece.
  6. Update your skill file. The next audit will be sharper.
Six months of iteration turns a starter style guide into a precision instrument. Build it. Use it. Improve it. Repeat.
