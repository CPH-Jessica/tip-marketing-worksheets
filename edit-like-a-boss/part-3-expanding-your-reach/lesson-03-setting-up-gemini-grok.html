Part 1
Gemini Gems + NotebookLM

Build Your ELAB Editor Gem Free Tier OK

Gemini's Custom GPT equivalent. Single Instructions field, attachable reference files. Free tier supports Gem creation.

1
Go to gemini.google.com/gems
Sign in with your Google account. If you've used Gemini before, you're already signed in.
2
Click "+ New Gem"
The button is in the Gems panel on the left side.
3
Name your Gem
Use "ELAB Editor" for a generic version, or "[Your Pen Name] Editor" for a pen-name-specific version.
4
Paste your full ELAB skill content into the Instructions field
Gemini accepts long content in this field — don't summarize. Include the full 8-pass system, banned list for the pen name, voice archetypes, and ask-for-inputs rules.
Instructions field — paste structure You are the ELAB Editor for [pen name]. You follow the 8-pass editing system: PASS 1 — Quality Check PASS 2 — Plot Hole Checker PASS 3 — Timeline Consistency PASS 4 — Line Edit PASS 5 — Dialogue Polish PASS 6 — Heat Scene Edit PASS 7 — Developmental Edit PASS 8 — Voice Audit BANNED WORDS / PHRASES: [paste list] VOICE ARCHETYPE: [paste profile] ASK-FOR-INPUTS RULES: [paste rules] Before starting any pass, ask which pass the author wants to run. Do not assume.
5
Upload your reference files
Click the file upload button. Add your codex, style guide, and 1-2 sample chapters that show the voice working at its best.
6
Save and pin to sidebar
Click Save. Then click the pin icon next to the Gem's name so it's always one click away.
Pro Tip Test it on a chapter you've already edited elsewhere. Compare Gemini's results to what Claude or ChatGPT gave you. You'll quickly learn where this tool is strong and where it isn't.

Gem Setup Checklist

Set Up Your NotebookLM Fiction Project Free

NotebookLM is separate from Gemini chat — it's Google's research notebook. Upload up to 50 sources per notebook. AI cites which file the info came from.

1
Go to notebooklm.google.com
Sign in with the same Google account you use for Gemini.
2
Click "+ New notebook"
3
Name it for the scope
Book-specific: "Skyler Knight Book 3 Research Notebook." Pen-name-wide: "Skyler Knight Brand Bible." Pick the scope that matches how you actually work.
4
Upload your sources
Drag and drop, or use the upload button. Accepts PDFs, Google Docs, text files, web pages, even YouTube transcripts.
5
Ask cross-referencing questions
This is where you get value back. Try the examples below in your own notebook.
Example questions to try Does Chapter 14's character knowledge violate what was established in Chapter 7? What banned words appear in Chapter 12? List every time the protagonist mentions her sister. Note any inconsistencies in how she's described. In Chapter 7 the hero said he had never been to Paris. Does anything in later chapters contradict that? Summarize the rules of the magic system as established across all uploaded chapters. Flag any contradictions.
6
Generate the Audio Overview
Click the audio overview button. Wait a few minutes. You'll get a 10-15 minute podcast-style discussion of your sources. Listen while you walk or drive. You'll hear things about your own book you forgot you wrote.
Why This Matters NotebookLM cites its sources. When it answers, it tells you which file the information came from. That makes it the strongest tool I've used for Pass 2 (Plot Hole Checker) and Pass 3 (Timeline Consistency).

Don't try to make one do the other's job. They're built for different work.

Part 2
Grok Setup

Build Your Grok Editing Setup Mostly Paid

Grok's custom assistant layer is less formalized than the other three platforms. You primarily work via system prompts you re-paste at the start of each chat.

Non-Developer Path (Most Authors)

1
Subscribe to Grok
Two options: X Premium+ ($30/mo, includes Grok), or directly via grok.com (SuperGrok, $30/mo standalone). Free tier exists but is limited.
2
Open a new chat
3
Paste your ELAB system prompt at the top of the chat
Same content as your Gemini Gem instructions. Paste it before you do anything else — it sets the context for the whole session.
Grok system prompt — paste at top of every chat You are my ELAB Editor for [pen name]. We're working through the 8-pass editing system. Before I share a chapter, ask which pass I want to run. PASS 1 — Quality Check PASS 2 — Plot Hole Checker PASS 3 — Timeline Consistency PASS 4 — Line Edit PASS 5 — Dialogue Polish PASS 6 — Heat Scene Edit PASS 7 — Developmental Edit PASS 8 — Voice Audit BANNED WORDS / PHRASES: [paste list] VOICE ARCHETYPE: [paste profile] ASK-FOR-INPUTS RULES: [paste rules] Acknowledge this prompt and ask which pass we're running. Do not begin editing until I tell you.
4
Save system prompts in a notes app for easy re-paste
I keep mine in a single notes document on my desktop, with a section per pen name. Every new Grok session starts with a copy-paste.

Advanced Path (Developers Only) Optional

5
xAI API for persistent custom agents
If you code (or work with a developer), the xAI API lets you build persistent Grok agents with baked-in system prompts and tool access. Outside the scope of this lesson, but it's there if you want it. Documentation at docs.x.ai.
Heads Up Grok doesn't have a persistent "Gem" or "GPT" you can pin. Every new chat starts blank. The system-prompt-and-paste workflow is the trade-off for using this tool. Build the habit early — it transfers to every AI tool, because every model accepts system prompts.

Where I'll Use Which Tool — Decision Tool

For each editing task below, pick the tool you'll reach for. There's no single right answer — this is YOUR map.

Pass 1 — Quality Check (rule-based, mechanical)
Pass 2 — Plot Hole Checker (cross-reference across chapters)
Pass 3 — Timeline Consistency
Pass 4 — Line Edit
Pass 5 — Dialogue Polish
Pass 6 — Heat Scene Edit (especially if dark/edgy content)
Pass 7 — Developmental Edit (whole-chapter analysis)
