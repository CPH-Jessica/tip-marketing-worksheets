Set Up Your PC Swap Agent

A click-by-click walkthrough — no tech knowledge assumed. About 15 minutes, one time.
0 of 8 steps done
What you're setting up: a little robot that lives on your PC. When you run it, a Chrome window opens, logs into BookClicker, BookSwappy, and BookFunnel, collects every swap you've signed up for, and hands you a file that loads straight into the Newsletter Composer. There's a second robot that books new swaps for each pen name. You set it up once (steps 1–5), then week-to-week it's one command.

Step 1 · Get the swap-agent folder onto your PC

⏱ ~3 minutes
  1. In your web browser, go to your repo: github.com/CPH-Jessica/tip-marketing-worksheets (log in to GitHub if it asks).
  2. Click the green <> Code button near the top right → click Download ZIP.
  3. Open your Downloads folder, right-click the ZIP file → Extract All… → Extract.
  4. Open the extracted folder. Inside you'll see a folder called swap-agent.
  5. Open File Explorer, go to your C: drive, right-click empty space → New → Folder, name it CPH.
  6. Drag (or copy-paste) the swap-agent folder into C:\CPH.
You should now have a folder at C:\CPH\swap-agent containing files like login.js, pull-swaps.js, and README.md.
💡 Heads-up: the ZIP downloads whatever branch GitHub shows. If you don't see swap-agent inside, switch the branch dropdown (top-left of the repo page) to claude/miller-life-sage-marjorie-emails-4jtdf6 before downloading — or merge PR #8 first and use main.

Step 2 · Install Node.js (the engine that runs the robot)

⏱ ~3 minutes
  1. Go to nodejs.org in your browser.
  2. Click the big green button that says LTS (it will say something like "Download Node.js (LTS)"). Don't pick "Current."
  3. Open the downloaded installer. Click Next on every screen — the default choices are all correct. Accept the license, click Install, let it finish, click Finish.
How to know it worked — you'll prove it in the next step. If a screen mentioned "Tools for Native Modules" with a checkbox, you can leave it unchecked.

Step 3 · Open PowerShell inside the swap-agent folder

⏱ ~1 minute — you'll do this little move every time you use the robot
  1. In File Explorer, open C:\CPH\swap-agent so you can see the files.
  2. Click once in the address bar at the top (where it shows the folder path). The path text highlights.
  3. Type powershell over it and press Enter.
You should see a blue or black window appear with a line ending in C:\CPH\swap-agent> and a blinking cursor. That's PowerShell, sitting in the right folder. Leave it open.
💡 That address-bar trick is the whole secret. Any time these instructions say "open PowerShell in the folder," it's those three clicks.

Step 4 · Install the robot's two dependencies

⏱ ~3 minutes (mostly waiting)

Copy each command below (use the Copy button), click into the PowerShell window, right-click to paste, press Enter, and wait for it to finish before doing the next one.

npm install
You should see a progress spinner, then something like "added 3 packages". Yellow "npm notice" lines are fine — ignore them.
npx playwright install chromium
You should see a download progress bar for "Chromium". This installs the robot's own private Chrome. When the cursor comes back, it's done.
⚠️ If PowerShell says "npm is not recognized": close the PowerShell window, redo Step 3 (the fresh window picks up Node). Still stuck? Restart the PC once and try again.

Step 5 · Log in once (the robot remembers forever)

⏱ ~3 minutes, one time
node login.js
  1. A Chrome window opens with three tabs: BookClicker, BookSwappy, BookFunnel.
  2. In each tab, log in with your usual account (the Jessica logins you use on the Mac).
  3. When all three show your dashboard, just close the browser window.
What just happened: your logins were saved into a private browser profile inside the folder. Every future run reuses them — no passwords are stored in any file, it's exactly like Chrome staying signed in.

Step 6 · Run the crawler! 🎉

⏱ ~2 minutes per run — this is your weekly command
node pull-swaps.js
You should see a Chrome window open and visit each platform while PowerShell narrates: "bookclicker: found 12 candidate swap entries…". When it says DONE, look in the new output folder inside swap-agent:
  • report-(date).html — double-click to review everything it found
  • composer-import.json — this is the file the Newsletter Composer eats
  • agent.log — running history of every run
🔎 First run = calibration run. If any platform reports 0 swaps, that's expected the first time — the sites' layouts vary. A snapshots folder will appear; send Claude the files inside it and say "calibrate the swap crawler," and the extractor gets tuned to the exact page layout. After that it's routine.

Step 7 · Plug the swaps into the Newsletter Composer

⏱ ~1 minute
  1. Open the CPH Newsletter Composer (book-marketing\cph-swap-module-builder.html — double-click it, it opens in your browser).
  2. On the left, click "Import swaps JSON (from the PC swap crawler)" to expand it.
  3. Click Choose File → pick C:\CPH\swap-agent\output\composer-import.json → click Import file.
  4. Switch between pen names (dropdown, top right) — each one's swaps are waiting in her preview. Trim, generate the opening note, export to MailerLite.
You should see "Imported N swap module(s)" and covers appearing in the preview. Anything the crawler couldn't confidently assign lands under whichever pen name is currently selected — move or delete those by eye.

Step 8 · The harvester (books new swaps) optional

⏱ whenever a pen name needs more swaps

Same PowerShell-in-the-folder move (Step 3), then:

node book-swaps.js --pen sage
Safe look-only mode: it lists every free, genre-matched partner it found for Sage — books nothing. Swap sage for connie, ruthie, marjorie, kelsey, or nora.
node book-swaps.js --pen sage --book
Booking mode: it opens each match, fills in the magnet + list, and asks you y/n in PowerShell before every submission. (Type stop to quit.) Once you trust it, add --yes to go fully automatic.
🛡️ Rules it always follows (from your swap playbooks): free mention swaps only · never anything with a price · no erotica/LGBTQ lists · one swap per author · genre & heat must match the pen name. Edit rules in config.js.

Make it run by itself optional

Schedule the crawler with Windows Task Scheduler (so it's "already doing the work")
  1. Press the Windows key, type Task Scheduler, open it.
  2. Right side: click Create Basic Task…
  3. Name: CPH swap pull → Next.
  4. Trigger: Weekly → Next → tick Mon, Tue, Wed (the mornings before your send days), time 7:00 AM → Next.
  5. Action: Start a program → Next, then fill in:
    • Program/script: C:\Program Files\nodejs\node.exe
    • Add arguments: pull-swaps.js --headless
    • Start in: C:\CPH\swap-agent
  6. Next → Finish. Done — each run quietly appends to output\agent.log and drops a fresh dated report you can check any morning.

If something goes wrong

"npm is not recognized" / "node is not recognized"
PowerShell was open before Node finished installing. Close the PowerShell window, redo Step 3. If it persists, restart the PC — that always fixes it.
A platform says "NOT LOGGED IN — run node login.js"
That site expired your session (they do this every few weeks). Run node login.js, log in to whichever tab asks, close the window, rerun the crawler.
The crawler found 0 swaps on a platform (but you know there are some)
Expected on the very first run — the extractor is deliberately cautious with unfamiliar page layouts. Look in the snapshots folder for files named like 2026-07-09-bookclicker-empty.html/.png, send them to Claude with "calibrate the swap crawler," and you'll get back a tuned version.
Windows pops a blue "protected your PC" / firewall box
For SmartScreen on the Node installer: click More info → Run anyway (it's the official installer from nodejs.org). For a firewall prompt about Node or Chromium: click Allow — the robot needs internet to reach the swap sites.
Red error text you don't understand
Don't fight it — select the text in PowerShell (drag over it), press Enter to copy, and paste it to Claude. Include which step you were on. Nine times out of ten it's a one-line fix.
